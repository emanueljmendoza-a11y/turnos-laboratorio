Importante: buscar mediante el BST cuesta O(log n) después de construir el índice. Como el proyecto reconstruye el árbol desde JSON en cada consulta, el costo total de esa consulta es O(n²), no O(log n). Los recorridos de recomendaciones también incluyen el costo O(n²) de construir su grafo y un ordenamiento por inserción O(V²). La ocupación del catálogo se calcula en una sola pasada por listas y diccionarios.

Cómo defender el proyecto

  1. Listas: JSON almacena colecciones de libros, lectores y movimientos.
  2. Árboles: el índice ISBN permite búsqueda binaria basada en nodos.
  3. Grafos: libros conectados forman una red recorrida con BFS.
  4. Montículos: se priorizan reservas por fecha y retrasos por días vencidos.
  5. Big O: se explica el costo de cada algoritmo y su construcción.
  6. JSON: las operaciones se mantienen tras cerrar el programa.
No se han creado clases propias; las operaciones se implementan con funciones, listas, diccionarios, condicionales y ciclos.
